# MSL ONE CVRM · 녹화 가이드

## 실행

1. 프로젝트의 `Start-CVRM.cmd`를 실행합니다. 이미 8000 포트에서 `api:app`이 실행 중이면 중복 실행하지 않습니다.
2. 브라우저에서 http://127.0.0.1:8000/cvrm 을 엽니다. 창을 닫거나 Ctrl+C를 누르면 서버가 종료됩니다.
3. 프론트엔드 개발 모드는 기존처럼 `npm run dev`로 실행합니다. 첫 화면의 CVRM에서 같은 검색 API를 사용합니다.

HTML 파일을 직접 열어도 저장된 출처·입력·차트·내보내기는 동작합니다. 파일 모드의 새 검색은 위 로컬 주소에서 실행합니다. 실제 검색과 뉴스 새로고침에는 인터넷이 필요하고, AI 키는 필요하지 않습니다. 외부 DB 장애·제한은 화면에 표시합니다.

## 약 4분 녹화 순서

| 구간 | 동작 | 설명 |
|---|---|---|
| 0:00–0:25 | 오늘의 브리핑 | 독립 포트폴리오 소개. 왼쪽 뉴스·오른쪽 체크리스트·한 줄의 네 소식을 보여줍니다. 경력 설명은 본인이 수행한 업무에 한정합니다. |
| 0:25–0:50 | 뉴스 카드에 마우스 올렸다 떼기 | 확인한 기사와 RSS 소식을 구분하고, 메모가 나타났다 사라지는 것을 보여줍니다. |
| 0:50–1:20 | 논문·임상 검색 | ‘김성균 교수 · 피네레논 논문’을 선택한 뒤 실제 검색. 출처별 전체 건수/표시 건수 확인. 실패하면 오류를 숨기지 않고 ‘확인해 둔 자료’로 전환합니다. |
| 1:20–1:45 | 문서 담기 | 확인해 둔 자료의 E01, E02, NCT02540993을 담습니다. 논문·임상·장바구니가 분리되어 있고 내용은 눌러 펼칠 수 있습니다. |
| 1:45–2:15 | HCP 방문 준비 | 이름·병원·과·제품과 기사/논문을 확인. ‘프로필·출처’에서 확인 범위를 열어보고 ‘논문·기사 검색’을 실행합니다. |
| 2:15–2:40 | 질문 직접 입력 | ‘환자의 검사 부담과 추적검사 역할은 원 연구에서 어떻게 다뤄졌나요?’ 입력. 질문 분야와 E01 출처를 골라 저장합니다. |
| 2:40–3:15 | 대화·후속 근거 | ‘연습 기록’을 불러와 접힌 관찰·해석·가설을 펼치고 검토·저장합니다. 실제 교수의 발언이 아닌 연습 메모임을 설명하고 질문 분야 그래프를 확인합니다. |
| 3:15–3:40 | 후속 검색 | ‘질문에서 검색어 만들기’ 후 수정하고 ‘관련 논문·임상·기사 찾기’. 초록·등록정보를 확인합니다. 네트워크 장애 시 ‘저장된 근거 예제’를 사용할 수 있습니다. |
| 3:40–4:00 | 방문 리포트 | 방문 전과 후를 전환. 문서 주제, 접힌 결과 도식, 질문 분야 그래프를 확인하고 HTML로 각각 내보냅니다. 긴 문서는 ‘리포트 전체 보기’로 엽니다. |

## 자막과 자료

`captions.ko.srt`와 `captions.en.srt`는 같은 4분 타임라인입니다. 실제 동작 속도에 맞춰 편집기에서 조정하세요. UI는 한국어 중심이고 영문 논문 제목/초록은 출처 언어를 유지합니다.

오프라인 녹화용 실제 자료는 `frontend/src/cvrm/verified-search.mjs`에 있습니다. PubMed 저자 검색 3건과 ClinicalTrials.gov의 FIDELIO-DKD, FIGARO-DKD, CONFIDENCE, VICTORIA 등록정보를 실제 API에서 확인해 저장했습니다. 저장 예제를 새 검색 결과로 설명하지 마세요.

사전 생성한 방문 전/후 리포트에는 연습 질문과 1건의 가상 교류가 포함됩니다. 앱에서 내보내는 리포트는 현재 브라우저의 선택과 기록을 사용합니다. 공유 전 내용을 검토하세요. 환자 식별정보·회사 기밀은 입력하지 않습니다. 공개 인물 프로필과 연습 대화는 구분합니다.

GCP는 Good Clinical Practice입니다. 출처 추적과 관찰/해석 분리 등 품질 원칙을 참고했으며 임상시험용 인증 또는 검증 시스템으로 설명하지 않습니다.

## 추가로 보여줄 검토 과정

방문 전 또는 방문 후 화면의 ‘초안 검토’를 눌러 옆 패널을 엽니다. 직접 쓴 문장이나 외부 AI 초안의 수정 문장·출처·확인 범위·수정 이유·검토자·판단·후속 질문을 남길 수 있습니다. 예제 버튼은 아시아 분석을 국내 진료에 적용할 때 표현 범위를 보완하는 연습입니다. 실제 AI가 생성한 결과나 전문가가 승인한 기록으로 설명하지 않습니다. 저장한 기록은 해당 단계의 HTML 리포트에 포함됩니다.

‘오늘의 브리핑’ 오른쪽 위의 ‘Bayer AI·Medical 자료’는 옆 패널로 열립니다. 글로벌·프랑스 PV·한국 오픈이노베이션의 범위를 표시했습니다. 한국 의학부 도입 현황으로 일반화하지 않습니다. 왼쪽 아래 ‘포트폴리오 안내’에는 사용자가 제공한 역량 표를 연결했습니다. 이 설명을 녹화에 추가하면 기존 4분 자막은 해당 부분에 맞춰 시간을 조정하세요.

뉴스 검색을 녹화할 때는 회색 예시를 참고해 검색어를 입력하고 Enter 또는 ‘뉴스 검색’을 누르세요. ‘새로고침’은 입력을 비우고 기본 Bayer/CV 뉴스로 돌아갑니다. 1280×720 이상을 권장하며, 긴 자료는 패널 안에서 스크롤합니다.

## 논문 검색 화면 안에서 리포트 보여주기

‘논문·임상 검색’에서 FIDELIO-DKD를 찾거나 PubMed 검색어 `33264825[PMID]`로 검색합니다. 해당 문서의 ‘리뷰 리포트 생성’을 누르면 상단 ‘리포트 FIDELIO-DKD’ 탭이 열립니다. ‘검색 결과’ 탭으로 돌아가도 리포트는 남습니다. 장바구니에 새 문서를 담아도 해당 리포트 탭이 등록됩니다.

리포트의 HR·신뢰구간과 효과/안전성 막대를 먼저 보여주고, 대상·설계, 결과, 안전성, 한계, HCP 질문 3개, 출처의 여섯 항목을 펼칩니다. 다른 문헌은 원문 검토 전 초안으로 표시됩니다. 이 화면은 LLM 연결 없이 동작합니다.

## 원문·리포트 닫기·CC와 질문 분석

- 새 기사를 누르면 오른쪽에서 원문 웹사이트를 읽습니다. 매체가 외부 표시를 차단하면 원문 링크로 엽니다.
- 2번과 3번 화면의 리포트는 각각 그 화면에 유지됩니다. 탭 오른쪽 ×는 리포트만 닫습니다.
- 4번 화면에서 직접 질문을 입력하고 ‘연습 자막’으로 CC·그래프를 시연할 수 있습니다. 연습 예제임을 밝히세요. 실제 음성은 지원 브라우저에서 ‘음성 인식 시작’을 누르고 마이크 권한을 허용해야 합니다. 자동 자막은 질문 입력란과 별도입니다.
- ‘질문 분석 · LLM’은 본인 OpenAI API 연결이 필요합니다. 기본값은 직접 입력한 질문만 분석합니다. ‘확정 자막도 LLM 분석에 포함’을 고르면 확정 자막도 보냅니다. API 연결과 실제 분석 결과를 구분해서 설명하세요. 키워드 그래프는 로컬 집계이고 LLM 호출이 아닙니다.
- 실제 음성과 유료 LLM 호출은 이번 검증에서 실행하지 않았습니다. 시연 전 본인 브라우저·마이크·API로 확인하세요.
